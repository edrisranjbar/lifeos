چرا ساخته شد

پنج برنامه، و هیچ‌کدام با هم حرف نمی‌زنند.

هر ابزار به‌تنهایی خوب است، اما کنار هم نمی‌توانند به تنها سؤالی که واقعاً مهم است جواب بدهند:

«آیا به سمت زندگی‌ای که می‌خواهم پیش می‌روم؟»

یک‌جا و به هم پیوسته

یازده فضای کاری. یک طراحی. یک پایگاه داده.

یک عادت می‌تواند پیشرفت یک هدف را جلو ببرد، کارت‌ها در تقویم‌تان می‌نشینند و نمای کلی همه را به یک امتیاز روزانه تبدیل می‌کند.

رشد

شش بُعد زندگی، یک مسیر

معنویت، سلامت، خانواده، مالی، یادگیری و استراحت؛ هر کدام وصل به هدف‌های بلندمدت و عادت‌هایی که پشتشان است. مرور هفتگی فقط یک یادداشت صادقانه و یک قدم بعدی از شما می‌خواهد.

Habittify

قدم‌های کوچک، هر روز

عادت‌هایی آن‌قدر کوچک که در شلوغ‌ترین روز هم انجام شوند؛ با زنجیرهٔ روزها و تقویم شمسی یا میلادی.

تمرکز

کار عمیق، با حال خوب

تایمر پومودورو با موسیقی و آسمانی که با ساعت روز عوض می‌شود.

کانبان

پروژه‌هایی که جلو می‌روند

بوردهایی با برچسب، اولویت، موعد، چک‌لیست، نظر و پیوست. هر کارت را می‌توانید به یک هدف تبدیل کنید.

حساب‌وکتابی که جور درمی‌آید

هزینه و بودجه به تومان یا هر ارز دیگر، به‌علاوهٔ بدهی‌ها و طلب‌ها، یک‌باره یا قسطی، که مستقیم در دفتر حساب ثبت می‌شوند.

هدف‌هایی که سنجیدنی‌اند

هدف‌های SMART که با چک‌لیست، معیار سنجش یا پایبندی به یک عادت پیش می‌روند.

یک تقویم برای همه چیز

موعد کارت‌ها و سررسیدهای مالی کنار هم، با علامت برای موارد عقب‌افتاده.

آمادهٔ هوش مصنوعی

از Claude دربارهٔ زندگی واقعی‌تان بپرسید.

سرور MCP داخلی، ۱۵ ابزار در اختیار Claude و دستیارهای دیگر می‌گذارد؛ برای داشبورد، هدف‌ها، کارها، عادت‌ها، امور مالی و یادداشت‌ها.

  • فقط از راه API. با یک API محافظت‌شده با توکن حرف می‌زند، هرگز مستقیم با پایگاه داده.
  • قبل از حذف می‌پرسد. ابزارهای حذف علامت‌گذاری شده‌اند تا اول از شما تأیید گرفته شود.
  • خصوصی، خصوصی می‌ماند. یادداشت‌های محرمانه پنهان می‌مانند، مگر خودتان اجازه بدهید.
  • بدون بازنویسی بی‌صدا. بررسی نسخه، از ویرایش‌های شما و هوش مصنوعی به یک اندازه محافظت می‌کند.

نصب در چند دقیقه

مال خودتان، هر جا که بخواهید.

PHP، MySQL و جاوااسکریپت ساده؛ بدون فریم‌ورک، بدون مرحلهٔ build و بدون چیزی که با به‌روزرسانی خراب شود.

ترمینال
# Get the code
$ git clone https://github.com/edrisranjbar/lifeos.git && cd lifeos
# Set your sign-in and passwords
$ cp .env.example .env
# Start the app and MySQL
$ docker compose up -d
# Open http://localhost:8080

داکر (Docker Compose)

برنامه و MySQL با volume جدا برای داده‌ها و پیوست‌ها. به‌روزرسانی فقط یک build دوباره است.

پرسش‌های رایج

پیش از شروع، شاید بپرسید…

آیا Edi Life OS رایگان است؟

بله. Edi Life OS کاملاً رایگان و متن‌باز با مجوز MIT است. اشتراک ماهانه، تبلیغ یا ردیابی ندارد و روی سرور خودتان اجرا می‌شود.

آیا روی هاست اشتراکی ایرانی کار می‌کند؟

بله. هر هاستی که PHP 8.1 به بالا و MySQL 8 یا MariaDB داشته باشد کافی است، از جمله هاست‌های اشتراکی cPanel و DirectAdmin. فایل zip آخرین نسخه را در پوشهٔ اصلی هاست باز کنید و اطلاعات پایگاه داده را وارد کنید.

آیا از تقویم شمسی و تومان پشتیبانی می‌کند؟

بله. تاریخ‌ها به وقت تهران هستند، Habittify می‌تواند تقویم جلالی (شمسی) را نشان دهد، ارز پیش‌فرض بخش مالی تومان است و یادداشت‌های فارسی خودکار راست‌به‌چپ نوشته می‌شوند.

داده‌های من کجا ذخیره می‌شود؟

فقط در پایگاه دادهٔ MySQL خودتان، روی سروری که خودتان انتخاب می‌کنید. هیچ داده‌ای به سرور دیگری فرستاده نمی‌شود.

چطور با هوش مصنوعی کار می‌کند؟

Edi Life OS یک سرور MCP اختیاری دارد که ۱۵ ابزار را در اختیار Claude و دستیارهای دیگر می‌گذارد. دستیار فقط از راه API محافظت‌شده با توکن کار می‌کند و به پایگاه داده یا رمزها دسترسی ندارد.
